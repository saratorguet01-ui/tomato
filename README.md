# Tomato

Data science project setup and exploratory analysis of Barcelona Airbnb listings.

## Project Structure
- `data/`: Local datasets (ignored by Git).
- `notebooks/`: Exploratory Jupyter notebooks (`explore.ipynb`).
- `reports/`: Generated figures and outputs.
- `src/ketchup/`: Custom installable Python package.
- `environment.yml`: Conda environment specification (`tomato_pot`).
- `pyproject.toml`: Package build configuration.
